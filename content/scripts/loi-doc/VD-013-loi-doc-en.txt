That thing you've avoided all week? The whole task isn't hard. The first ten minutes are.

The file you've closed three times. The dishes in the sink. The message you read yesterday and never answered.

Before you start, each one feels enormous. The file becomes a whole project. The dishes become the whole kitchen. The message needs perfect words.

But you haven't done any work yet. You're standing outside, imagining all of it at once.

Don't promise to finish. Set ten minutes. Your only job is to stay until the timer rings.

Write one bad first line. Wash the first bowl. Type one honest sentence: “Sorry I took so long to reply.”

These ten minutes aren't for doing it well. They're for touching the task instead of growing it in your head.

When the timer rings, you may stop. Really. Save the file. Leave the dishes. Send the message only if it's ready.

That permission matters. If “ten minutes” secretly means “until it's finished,” you won't trust the timer next time.

Sometimes the timer rings and you keep moving. Fine. That's your choice now.

If you stop, those ten minutes still count. There is less left, and you know where to begin next time.

Just make the first step small enough to take.

Pick what you've been avoiding. Set ten minutes now. When it rings, tell me: stopped, or kept going?
