# Thư mục VIDEO — không lưu trên GitHub

Thư mục này **cố tình bị loại khỏi Git** (xem [.gitignore](../.gitignore)) vì file video rất nặng.

Chỉ có file `README.md` này được đưa lên GitHub để giữ lại cấu trúc và ghi chú.

## Cách tổ chức
- `raw/` — footage quay gốc, chưa dựng
- `edit/` — file dự án đang biên tập (CapCut/Premiere...)
- `exports/` — video đã render xong, sẵn sàng đăng
- `thumbnails/` — ảnh bìa

## Lưu ý
File thật nằm ở máy anh. Nên sao lưu định kỳ ra ổ cứng ngoài hoặc cloud (Google Drive/iCloud) vì GitHub **không** giữ bản sao cho phần này.
